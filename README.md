# Signal Explorer — DSP Toolkit

A mobile-style Digital Signal Processing learning toolkit built with React, Vite, Tailwind CSS, and Recharts.

## Local development

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

Output goes to `dist/`.

## Deploy

This repo includes a `netlify.toml` so it deploys to Netlify with zero config —
just connect the repo in Netlify and it will run `npm run build` and publish `dist/`.
